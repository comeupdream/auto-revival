# Hero car photos

Drop the two hero photos in this folder — no code changes needed:

- `car-left.jpg` — shown to the **left** of the logo behind the curtain
- `car-right.jpg` — shown to the **right** of the logo

Also accepted: `.jpeg`, `.png`, `.webp`, or the names `car-1.*` (left) and
`car-2.*` (right). Landscape shots around 1200×900 look best (they're shown
in a 4:3 gold frame).

Until the files exist, the site shows a gold-framed "photo coming soon"
placeholder in each spot.
